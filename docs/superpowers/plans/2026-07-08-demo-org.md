# Demo Org Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up a single always-on `studio_plus_inventory` demo organisation that anyone can enter with one click from the sign-in page, browse a curated Print Room catalogue (tee + hood carrying the Print Room left-chest logo, plus stocked extras) at real Print Room prices, draw down live inventory, and complete a fully-sandboxed checkout — reset nightly.

**Architecture:** Two repos. (A) `print-room-staff-portal` gets an idempotent `tsx` seed script (`scripts/demo-org/`) that provisions/reconciles the whole org graph via the service-role key, plus a nightly GitHub Actions job that re-runs it to purge demo transactions and restock. (B) `print-room-portal` gets a public `GET /api/demo/enter` route that server-signs the shared demo user in and redirects into the storefront, an "Explore the demo" button on the sign-in page, and a one-line order-email guard so `is_test` orgs never email a real customer.

**Tech Stack:** Next.js 16 (App Router, `@supabase/ssr`), Supabase Postgres (project `bthsxgmcnbvwwgvdveek`), `@supabase/supabase-js` service-role, `tsx` scripts, Vitest, GitHub Actions cron, Resend (email), Vercel (portal hosting/env).

## Deviations from the spec (discovered during research — carried into this plan)

1. **`product_pricing_tiers` is empty for all demo products.** The spec's "copy master `product_pricing_tiers`" step is impossible. Real prices live only in existing orgs' typed `b2b_catalogue_item_pricing_tiers`; **Anytime "Winter 26" holds all of them and its numbers match the spec exactly** (Tee $42.22, Hood $70.28, Cap $30.76, Duffel $32.12). That catalogue is the copy source.
2. **"Tier 1 multiplier applies on top" is wrong for `manual_final`** (RPC `effective_unit_price_for_item` forces the multiplier to `1.0`). Tier 1 is retained for structural realism only.
3. **Claremont Drink Bottle has 0 product images** → dropped. Demo catalogue = **4 items** (tee, hood, cap, duffel), all with real images and real Anytime ladders. A 5th accessory can be added later only if it exists in a reference catalogue and has images.
4. **Order-confirmation email has NO `is_test` guard** (`lib/checkout/submit.ts` sends to the customer regardless). Task B1–B2 add it.
5. **Post-welcome landing is `/shop`, not `/catalogue`** (proxy.ts has no `/catalogue` redirect; the welcome CTA pushes `/shop`). The demo route targets `/shop`.
6. **No cron infrastructure exists in the staff portal** (no `vercel.json`, no `app/api/cron`). The nightly reset is a **GitHub Actions scheduled workflow** running the seed script (Task A7).

```ts
import { DECORATION_LADDER, PREFERRED_COLOUR_LABELS } from './config'

/** Per-unit left-chest decoration price for the band covering `qty`. */
export function decorationPriceForQty(qty: number): number {
  const band =
    DECORATION_LADDER.find((b) => qty >= b.min && (b.max === null || qty <= b.max)) ??
    DECORATION_LADDER[DECORATION_LADDER.length - 1]
  return band.price
}

/** Choose up to 3 swatch ids, preferring white/black/navy by label, else lowest positions. */
export function pickColourSwatchIds(
  swatches: { id: string; label: string; position: number }[],
): { ids: string[]; defaultId: string | null } {
  const byPref: typeof swatches = []
  for (const want of PREFERRED_COLOUR_LABELS) {
    const hit = swatches.find((s) => s.label.toLowerCase().includes(want))
    if (hit && !byPref.includes(hit)) byPref.push(hit)
  }
  const filler = [...swatches].sort((a, b) => a.position - b.position)
  for (const s of filler) {
    if (byPref.length >= 3) break
    if (!byPref.includes(s)) byPref.push(s)
  }
  const chosen = byPref.slice(0, 3)
  const navy = chosen.find((s) => s.label.toLowerCase().includes('navy'))
  return { ids: chosen.map((s) => s.id), defaultId: navy?.id ?? chosen[0]?.id ?? null }
}
```

```ts
// scripts/demo-org/seed-identity.ts
import type { SupabaseClient } from '@supabase/supabase-js'
import { log } from './client'
import {
  DEMO, SYSTEM_USER_ID, TIER_1_ID, ACCOUNT_MANAGER_ID,
} from './config'

export interface DemoIds { orgId: string; accountId: string; storeId: string; userId: string }

async function findOrInsert<T extends { id: string }>(
  supabase: SupabaseClient, table: string, match: Record<string, unknown>, insert: Record<string, unknown>,
): Promise<string> {
  const { data: existing } = await supabase.from(table).select('id').match(match).maybeSingle()
  if (existing) {
    await supabase.from(table).update(insert).eq('id', (existing as T).id)
    return (existing as T).id
  }
  const { data, error } = await supabase.from(table).insert(insert).select('id').single()
  if (error) throw new Error(`${table} insert failed: ${error.message}`)
  return (data as T).id
}

/** Find the shared demo auth user by email, creating it if absent. Keeps the password fixed. */
async function ensureDemoAuthUser(supabase: SupabaseClient): Promise<string> {
  const password = process.env.DEMO_PASSWORD
  if (!password) throw new Error('DEMO_PASSWORD must be set (used to create/keep the shared demo user)')

  // Page through admin users to find the demo email (idempotent).
  for (let page = 1; page <= 50; page++) {
    const { data, error } = await supabase.auth.admin.listUsers({ page, perPage: 200 })
    if (error) throw new Error(`listUsers failed: ${error.message}`)
    const hit = data.users.find((u) => u.email?.toLowerCase() === DEMO.demoEmail)
    if (hit) {
      await supabase.auth.admin.updateUserById(hit.id, { password, email_confirm: true })
      return hit.id
    }
    if (data.users.length < 200) break
  }
  const { data, error } = await supabase.auth.admin.createUser({
    email: DEMO.demoEmail, password, email_confirm: true,
  })
  if (error || !data.user) throw new Error(`createUser failed: ${error?.message}`)
  return data.user.id
}

export async function seedIdentity(supabase: SupabaseClient, apply: boolean): Promise<DemoIds> {
  if (!apply) {
    log('identity', `would upsert org "${DEMO.orgName}" (DEMO, is_test), studio_plus_inventory account, store, demo user ${DEMO.demoEmail}, staff membership`)
    return { orgId: 'DRY', accountId: 'DRY', storeId: 'DRY', userId: 'DRY' }
  }

  const orgId = await findOrInsert(supabase, 'organizations',
    { customer_code: DEMO.customerCode },
    { name: DEMO.orgName, customer_code: DEMO.customerCode, is_test: true, deleted_at: null })
  log('identity', `org ${orgId}`)

  const accountId = await findOrInsert(supabase, 'b2b_accounts',
    { organization_id: orgId },
    {
      organization_id: orgId, company_name: DEMO.orgName,
      tenant_type: DEMO.tenantType, pricing_mode: 'tier',
      customer_tier_id: TIER_1_ID, account_manager_id: ACCOUNT_MANAGER_ID,
      payment_terms: 'net30', is_active: true,
    })
  log('identity', `account ${accountId} (studio_plus_inventory, tier1)`)

  const userId = await ensureDemoAuthUser(supabase)
  await supabase.from('profiles').upsert(
    { id: userId, email: DEMO.demoEmail, full_name: DEMO.memberFullName },
    { onConflict: 'id' })
  log('identity', `demo user ${userId}`)

  const storeId = await findOrInsert(supabase, 'stores',
    { organization_id: orgId, name: DEMO.storeName },
    { organization_id: orgId, name: DEMO.storeName, city: 'Auckland', country: 'New Zealand', created_by: SYSTEM_USER_ID })
  log('identity', `store ${storeId}`)

  // Membership: role 'staff' (store-member view). staff requires default_store_id.
  const { data: existingMember } = await supabase.from('user_organizations')
    .select('id').eq('user_id', userId).maybeSingle()
  const memberRow = {
    user_id: userId, organization_id: orgId, role: 'staff',
    default_store_id: storeId, ordering_permission: 'both',
  }
  if (existingMember) await supabase.from('user_organizations').update(memberRow).eq('id', existingMember.id)
  else await supabase.from('user_organizations').insert(memberRow)
  log('identity', `membership staff @ store ${storeId}, ordering=both`)

  return { orgId, accountId, storeId, userId }
}
```

```ts
async function copyPricing(supabase: SupabaseClient, itemId: string, product: DemoProduct) {
  // Find Anytime "Winter 26" item for the same source product.
  const { data: src } = await supabase.from('b2b_catalogue_items')
    .select('id, b2b_catalogues!inner(organization_id, name)')
    .eq('source_product_id', product.sourceProductId)
    .eq('b2b_catalogues.organization_id', ANYTIME_ORG_ID)
    .eq('b2b_catalogues.name', ANYTIME_CATALOGUE_NAME)
    .maybeSingle()
  if (!src) throw new Error(`No Anytime "${ANYTIME_CATALOGUE_NAME}" ladder for ${product.name}`)

  const { data: tiers } = await supabase.from('b2b_catalogue_item_pricing_tiers')
    .select('min_quantity, max_quantity, unit_price')
    .eq('catalogue_item_id', src.id).order('min_quantity')
  if (!tiers?.length) throw new Error(`Empty Anytime ladder for ${product.name}`)

  const rows = tiers.map((t) => ({
    catalogue_item_id: itemId,
    min_quantity: t.min_quantity,
    max_quantity: t.max_quantity,
    unit_price: t.unit_price,
    decoration_unit_price: product.decorated ? decorationPriceForQty(t.min_quantity) : null,
  }))
  const { error } = await supabase.from('b2b_catalogue_item_pricing_tiers')
    .upsert(rows, { onConflict: 'catalogue_item_id,min_quantity' })
  if (error) throw new Error(`pricing upsert ${product.name}: ${error.message}`)
  return rows.length
}

async function seedColours(supabase: SupabaseClient, itemId: string, product: DemoProduct) {
  const { data: swatches } = await supabase.from('product_color_swatches')
    .select('id, label, position').eq('product_id', product.sourceProductId).eq('is_active', true)
  if (!swatches?.length) { log('catalogue', `${product.key}: no swatches, skipping colours`); return }
  const { ids, defaultId } = pickColourSwatchIds(swatches)
  const rows = ids.map((id, i) => ({
    catalogue_item_id: itemId, color_swatch_id: id, sort_order: i, is_default: id === defaultId,
  }))
  const { error } = await supabase.from('b2b_catalogue_item_colors')
    .upsert(rows, { onConflict: 'catalogue_item_id,color_swatch_id' })
  if (error) throw new Error(`colours ${product.key}: ${error.message}`)
}

async function seedImages(supabase: SupabaseClient, itemId: string, product: DemoProduct): Promise<string | null> {
  // Reuse published product images. Delete-then-insert for idempotency.
  const { data: imgs } = await supabase.from('product_images')
    .select('file_url, view, color_swatch_id, position')
    .eq('product_id', product.sourceProductId).order('position').limit(6)
  await supabase.from('b2b_catalogue_item_images').delete().eq('catalogue_item_id', itemId)
  if (!imgs?.length) { log('catalogue', `${product.key}: no images`); return null }
  const rows = imgs.map((im, i) => ({
    catalogue_item_id: itemId, view: im.view ?? 'front', image_url: im.file_url,
    color_swatch_id: im.color_swatch_id, source: 'product', position: i, is_published: true,
  }))
  const { data: inserted, error } = await supabase.from('b2b_catalogue_item_images').insert(rows).select('id, view, position')
  if (error) throw new Error(`images ${product.key}: ${error.message}`)
  const front = inserted.find((r) => (r.view ?? '').toLowerCase().includes('front')) ?? inserted[0]
  return front?.id ?? null
}

export async function seedCatalogue(supabase: SupabaseClient, ids: DemoIds, apply: boolean): Promise<Map<string, string>> {
  const itemIds = new Map<string, string>()
  if (!apply) {
    log('catalogue', `would upsert catalogue "${DEMO.catalogueName}" + ${PRODUCTS.length} items, copy Anytime ladders, seed colours/images`)
    return itemIds
  }
  const catalogueId = await upsertCatalogue(supabase, ids.orgId)
  log('catalogue', `catalogue ${catalogueId}`)

  for (const product of PRODUCTS) {
    const { data: existing } = await supabase.from('b2b_catalogue_items')
      .select('id').eq('catalogue_id', catalogueId).eq('source_product_id', product.sourceProductId).maybeSingle()
    let itemId: string
    const baseRow = {
      catalogue_id: catalogueId, source_product_id: product.sourceProductId,
      name: product.name, price_mode: 'manual_final', is_active: true, sort_order: product.sortOrder,
    }
    if (existing) { itemId = existing.id; await supabase.from('b2b_catalogue_items').update(baseRow).eq('id', itemId) }
    else {
      const { data, error } = await supabase.from('b2b_catalogue_items').insert(baseRow).select('id').single()
      if (error) throw new Error(`item ${product.key}: ${error.message}`)
      itemId = data.id
    }
    itemIds.set(product.key, itemId)

    const bands = await copyPricing(supabase, itemId, product)
    await seedColours(supabase, itemId, product)
    const cardImageId = await seedImages(supabase, itemId, product)
    if (cardImageId) await supabase.from('b2b_catalogue_items').update({ card_image_id: cardImageId }).eq('id', itemId)
    log('catalogue', `${product.key}: item ${itemId}, ${bands} price bands${product.decorated ? ' (+decoration)' : ''}`)
  }
  return itemIds
}
```

```ts
// scripts/demo-org/seed-inventory.ts
import type { SupabaseClient } from '@supabase/supabase-js'
import { log } from './client'
import { PRODUCTS, INVENTORY_PLAN, STOCK_LEVELS } from './config'
import type { DemoIds } from './seed-identity'

export async function seedInventory(supabase: SupabaseClient, ids: DemoIds, apply: boolean): Promise<void> {
  if (!apply) { log('inventory', 'would seed variant_inventory with mixed in/low/out states'); return }
  for (const product of PRODUCTS) {
    const plan = INVENTORY_PLAN[product.key]
    if (!plan) continue
    const { data: variants } = await supabase.from('product_variants')
      .select('id, size_id').eq('product_id', product.sourceProductId).eq('is_active', true)
      .order('size_id', { nullsFirst: false }).limit(plan.states.length)
    if (!variants?.length) { log('inventory', `${product.key}: no variants`); continue }

    const rows = variants.map((v, i) => {
      const state = plan.states[i] ?? 'in'
      const lv = STOCK_LEVELS[state]
      return {
        variant_id: v.id, organization_id: ids.orgId, size_id: v.size_id,
        stock_qty: lv.stock_qty, committed_qty: 0, reorder_point: lv.reorder_point,
        allow_order_without_stock: lv.allow_order_without_stock,
      }
    })
    const { error } = await supabase.from('variant_inventory')
      .upsert(rows, { onConflict: 'variant_id,organization_id' })
    if (error) throw new Error(`inventory ${product.key}: ${error.message}`)
    log('inventory', `${product.key}: ${rows.length} rows (${plan.states.join('/')})`)
  }
}
```

```ts
// scripts/demo-org/reset.ts
import type { SupabaseClient } from '@supabase/supabase-js'
import { log } from './client'
import type { DemoIds } from './seed-identity'

export async function resetDemoTransactions(supabase: SupabaseClient, ids: DemoIds): Promise<void> {
  if (ids.orgId === 'DRY') return

  // Demo quotes (parent of orders + quote_* children).
  const { data: quotes } = await supabase.from('quotes').select('id').eq('organization_id', ids.orgId)
  const quoteIds = (quotes ?? []).map((q) => q.id)

  if (quoteIds.length) {
    // Children referencing quote_id first.
    for (const t of ['orders', 'quote_items', 'quote_artwork', 'quote_history', 'quote_status_history']) {
      const { error } = await supabase.from(t).delete().in('quote_id', quoteIds)
      if (error && !/does not exist|column .* does not exist/i.test(error.message)) throw new Error(`${t}: ${error.message}`)
    }
    await supabase.from('job_trackers').delete().in('quote_id', quoteIds)
    await supabase.from('quotes').delete().in('id', quoteIds)
  }
  // Job trackers tied to the demo user (email-fallback safety — see cross-tenant audit).
  await supabase.from('job_trackers').delete().eq('user_id', ids.userId)

  // Demo carts (keyed by user_id) + their items.
  const { data: carts } = await supabase.from('carts').select('id').eq('user_id', ids.userId)
  const cartIds = (carts ?? []).map((c) => c.id)
  if (cartIds.length) {
    await supabase.from('cart_items').delete().in('cart_id', cartIds)
    await supabase.from('carts').delete().in('id', cartIds)
  }
  log('reset', `purged ${quoteIds.length} quotes, ${cartIds.length} carts, demo job_trackers`)
}

// Standalone CLI: `npx tsx scripts/demo-org/reset.ts --apply`
if (require.main === module) {
  ;(async () => {
    const { getServiceClient, APPLY } = await import('./client')
    const { seedIdentity } = await import('./seed-identity')
    const { seedInventory } = await import('./seed-inventory')
    const supabase = getServiceClient()
    const ids = await seedIdentity(supabase, APPLY) // resolves existing ids without structural change
    if (!APPLY) { log('reset', 'dry-run — would purge demo transactions and restock'); return }
    await resetDemoTransactions(supabase, ids)
    await seedInventory(supabase, ids, true)
    log('reset', 'done')
  })().catch((e) => { console.error(e); process.exit(1) })
}
```

### Task B3: One-click demo entry route

**Files:**
- Create: `app/api/demo/enter/route.ts`

**Interfaces:**
- Produces: `GET /api/demo/enter` — server-signs the shared demo user in (password grant), persists `@supabase/ssr` cookies, sets `welcome_seen`, redirects to `/shop`.

- [ ] **Step 1: Write the route** (mirrors `app/(auth)/callback/route.ts`'s `createServerClient` + `response.cookies` pattern — the session cookies must be real so `proxy.ts`'s `getUser()` resolves the demo user).

```ts
// app/api/demo/enter/route.ts
import { type NextRequest, NextResponse } from 'next/server'
import { createServerClient } from '@supabase/ssr'

export async function GET(request: NextRequest) {
  const email = process.env.DEMO_EMAIL
  const password = process.env.DEMO_PASSWORD
  if (!email || !password) {
    return NextResponse.redirect(new URL('/sign-in?error=demo_unavailable', request.url))
  }

  // Land straight in the storefront; pre-set welcome_seen so the interstitial is skipped.
  const response = NextResponse.redirect(new URL('/shop', request.url))
  response.cookies.set('welcome_seen', 'true', { path: '/', maxAge: 60 * 60 * 24 * 365, sameSite: 'lax' })

  const supabase = createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
    {
      cookies: {
        getAll: () => request.cookies.getAll(),
        setAll: (cookiesToSet) =>
          cookiesToSet.forEach(({ name, value, options }) => response.cookies.set(name, value, options)),
      },
    },
  )

  const { error } = await supabase.auth.signInWithPassword({ email, password })
  if (error) {
    return NextResponse.redirect(new URL('/sign-in?error=demo_failed', request.url))
  }
  return response
}
```
